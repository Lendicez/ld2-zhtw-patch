## 這輪查證帶來的修正

**免 UAC 要看實際權限。**〔文件〕Steam 把「驗證檔案」與「修復遊戲庫權限」分列，所查官方文件沒有保證驗證會保留或重設 ACL；Program Files 下的 Steam 遊戲庫也不能直接判為不可寫。[驗證說明](https://help.steampowered.com/en/faqs/view/0C48-FCBD-DA71-93EB)、[權限修復說明](https://help.steampowered.com/en/faqs/view/21F5-8D5D-0141-7A5E)

〔文件：靜態〕EXE 有 `\USR`、`.\ld95.ini`、`.LDP`／`.LDE` 檔名樣式與檔案／登錄寫入 API，**尚不能證明寫入只有兩處**。因 Steam 遊戲庫本來就可寫（見「擁有者決定」的量測），補丁不改 ACL。

〔量測〕目前免 UAC、媒體正常及主視窗會拉回的結果，只涵蓋和良既有環境。〔回報〕玩家調整內建速度後獲改善，支持首批先做操作引導。[原討論](https://steamcommunity.com/app/335420/discussions/0/3734079922553501087/)

## 擁有者決定（2026-11-16）

- **受限遊戲庫 ACL**：不做（Steam 遊戲庫本來就可寫，見下方量測）。
- **第 2 批順序**：單格移動／鍵盤操作先，存檔快照後。
- **Steam Deck／Proton**：暫不列支援目標；有回報再評估。
- **可選介面放大（DPI 模式）**：擁有者無法切換顯示縮放實測，**本期不發行 DPI 選項**（未實測不出貨）。改為在 README 說明：高縮放螢幕可在 `Ld95.exe` 內容 → 相容性 → 變更高 DPI 設定 → 「覆寫高 DPI 縮放行為：系統（增強）」（玩家回報 R01 有效），由玩家自行決定。日後有 150%／200% 實測環境再做。

量測（受限遊戲庫 ACL）：擁有者主機上 Steam 安裝資料夾 `C:\Program Files (x86)\Steam` 本身帶 `BUILTIN\Users:(F)` 並繼承到 `steamapps\common`；`D:\SteamLibrary` 則是 `Authenticated Users:(M)`。Steam 遊戲庫不論在 Program Files 或其他磁碟，一般使用者原本就可寫（Steam 安裝程式自己設的）。免 UAC 只需「一般權限寫入檢查通過才啟用」；檢查失敗就維持原模式並提示 Steam 的「修復遊戲庫資料夾」。

## 本期不做

- 全螢幕化、DirectDraw wrapper、主視窗離屏救援：缺少本作相應故障證據。
- 全域降速、鎖 FPS、綁單核、高精度計時器：先用既有速度設定。
- Unicode 化、UTF-8 manifest、預設附語系模擬器：超出 CP950 補丁範圍。
- 任何 ACL 修改（窄範圍或全目錄）、整個 Steam 提升：Steam 遊戲庫本來就可寫，不需要。
- 散布完整遊戲或轉碼媒體、先換音訊後端：先定位可重現問題。
- 分軌音量、ASLR／DEP／LAA 旗標：未有本期收益與相容性證據。
- 隨時自動存檔、改 LDP、強制搬存檔：維持原存檔規則與格式。
