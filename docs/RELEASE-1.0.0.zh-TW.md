發行日：2026-11-08。發行經專案擁有者（和良）批准。

## 檔案

- `LD2-zhTW-Patch-1.0.0.exe`：安裝／解除安裝程式（.NET Framework 4，Windows 內建；未簽章）。
- 雜湊見 GitHub Release 說明（`installer_sha256`、`payload_sha256`）。

## 支援版本

| 項目 | 值 |
|---|---|
| 遊戲 | Steam 版 Lunatic Dawn: Passage of the Book |
| `Ld95.exe` | 1.0.3.16，7,090,176 B，sha256 `6c817a0978cd9f02b66a7f15e6e46b752e490eaffaa520e18d360d296d40d5d2` |
| 系統 | Windows 10／11，非 Unicode 程式語言＝中文（繁體，台灣）（ACP 950） |

其他版本、其他補丁或檔案被改過時，安裝程式顯示「不支援的檔案版本」並且不寫入任何檔案。

## 安裝程式行為

1. 自動讀 Steam 登錄與 `libraryfolders.vdf` 找 `steamapps\common\*\Ld95.exe`；也可手動選資料夾。
2. 逐檔核對原版 sha256 → 由差分重建目標檔 → 核對目標 sha256，全部通過才開始寫入。
3. 原檔先複製到 `<遊戲資料夾>\_zhTW_backup\original\` 並核對；已有同內容備份則沿用，不覆寫不同內容的備份。
4. 逐檔以暫存檔寫入、核對後取代；任何一步失敗即以備份回滾已寫入的檔案。
5. 解除安裝：只在檔案仍是本版補丁時，以核對過的備份還原。
6. 遊戲執行中拒絕操作；資料夾需要權限時詢問是否以系統管理員重新開啟（UAC）。
7. 不碰 `Usr`（存檔）、`ld95.ini` 與其他檔案；無網路、無遙測。

修改的檔案（124 個）：`Ld95.exe`、`RES` 內 53 張圖（BMP／BMH）、`index.html`、`マニュアル\*.html`（69 頁）。

## 已知限制

- 文字顯示依賴系統代碼頁 950；其他語系的 Windows 會出現亂碼。
- `ld95.chm`（遊戲選單「說明」）維持日文原版：本機沒有 HTML Help 編譯器。遊戲資料夾的 HTML 說明書已翻譯。
- 稱號在角色詳情視窗為繁中；其他畫面（如傳聞中提到）可能顯示日文（v4 catalog 空間不足）。
- 隨機產生、未收錄的名字以假名逐字音譯為漢字，可能不通順。
- 戰鬥中的法術／道具／逃跑、戰果、升級、彩票購買等畫面為靜態翻譯，未逐一實機確認；發現缺失請附截圖回報。
- 圖片上的字為細明體點陣；介面文字為微軟正黑體，風格略有不同。
- 原日文骰子「壱弐参」、英文 logo、製作名單、方位字母保留原樣。
- Steam 驗證檔案完整性或遊戲更新會還原原版，需重新安裝。
