發行日：2026-11-17。經專案擁有者實機確認（測試版 rc2）後出版。原始碼：分支 `release/1.0.3`（commit `579080c`；說明書譯文在本機建置資料）。

- `LD2-zhTW-Patch-1.0.3.exe` sha256 `becda46e96e745b82a6ca8dbed8df2b91a9e0ca17048b3012a069be0a3cee57f`（1,155,584 B）
- 支援版本、需求同 [1.0.0](RELEASE-1.0.0.zh-TW.md)。遊戲內文字與 1.0.2 相同。
- 已裝過 1.0.2：本版安裝程式會顯示「已安裝本版繁中補丁」（遊戲檔案相同），可直接使用下方新選項。
  已裝過 1.0.0／1.0.1：顯示「更新」。

這一版是「現代環境強化」的第一批（方案見 [OPTIMIZATION-PLAN](OPTIMIZATION-PLAN.zh-TW.md)）。

## 新增

- **免系統管理員權限啟動**（安裝程式選項）：原版每次啟動遊戲都會跳出 UAC 提示（程式宣告需要系統管理員權限，
  是早年為了能寫入遊戲資料夾裡的存檔）。安裝程式先以一般權限實際檢查能否寫入遊戲資料夾、`Usr` 存檔、`ld95.ini`，
  通過才可勾選；勾選後只把 `Ld95.exe` 內的權限宣告改為「以目前使用者身分執行」，遊戲啟動不再出現 UAC 提示。
  Steam 遊戲庫（含預設的 `C:\Program Files (x86)\Steam`）本來就允許一般使用者寫入，通常都能使用。
  隨時可再執行安裝程式取消勾選並按「套用」改回原版設定；解除安裝會完整還原。
- **環境提示**：安裝程式偵測到「Beta：使用 Unicode UTF-8 提供全球語言支援」開啟、系統地區不是繁體中文、
  或缺少 Windows Media 元件（Windows N 版，會沒有背景音樂）時，會說明原因與設定位置（不會自動更改系統）。
- **第一次遊玩建議**：安裝完成後提示遊戲內建的「遊戲設定」（移動速度）、「戰鬥設定 → 輸入時間」調到最慢
  （戰鬥會一直等你下指令）、視窗並排／重疊排列；並新增「開啟繁中說明書」按鈕。

## 修正

- 繁中說明書：「開場動畫／開場影片」統一為遊戲選單用語「片頭動畫」。

## 高解析度螢幕

- 縮放 150% 以上（筆電、4K）時遊戲畫面偏小。本版不改遊戲的縮放宣告（尚未在高縮放環境實測）。
  需要放大時可自行在 `Ld95.exe` 按右鍵 →「內容」→「相容性」→「變更高 DPI 設定」→ 勾選「覆寫高 DPI 縮放行為」，
  選「系統（增強）」（玩家回報有效；畫面會較模糊）。

## 存檔相容性

- 與 1.0.2 相同，沒有變更。
