# m036 翻譯現況與下一批內容

本輪沒有新增譯文。現有 m020 catalog 共 239 個文字資源位置、178 種去重
目標字串，另有 15 個字型設定位置；這不是全遊戲覆蓋率。

| 類別 | 已寫入位置 |
|---|---:|
| 選單 | 93 |
| 對話框標題 | 12 |
| 對話框控制項 | 79 |
| RT_STRING | 55 |

內容主要包括主選單、存讀檔／確認、部分角色資訊與系統 UI，以及陣形、
委託一覽、開鎖、魔法／道具對話框的有限文字。格式參數、資源與控制項
識別均保留；已驗證可以重建固定雜湊的 m020 EXE。

39 個位置沿用先前有限畫面證據：33 個可見文字、6 個只看過狀態列而非
tooltip。其餘 200 個位置只有靜態驗證。目前這份完整 catalog 的
current_version_game_seen 全部為 false；不能把歷史局部觀察當成當前整版
遊戲內通過。也不能以候選字串數估算全遊戲翻譯比例。

## 主要尚未完成來源

- 標準 menu/dialog/RT_STRING 中尚未審核的顯示文字，以及 MFC 錯誤提示。
  一部分需先確認命令／控制項語境，不能看到日文就盲目替換。
- EXE 的動態 ANSI／CP932 訊息、列表與記錄名稱。DBCS 切割、格式參數、
  下游 buffer 與字型路徑仍限制可安全寫入的文字。
- 外部 HF／資料記錄及故事、委託內容、物品與魔法描述。完整抽取／回寫
  與語境範圍仍未建立，不從候選數推算完成率。
- 存檔標頭裡既有日期文字；先前問號已追到既有標頭，不能改一個猜測的
  格式字串就宣稱修復。私人存檔不進 repo。
- 圖片內文字按原需求暫不處理。

現有 ACP950 標準 UI 路線不是全引擎 Unicode。原生 Unicode adapter
尚未整合，歷史封鎖元件不可藉新包、改名或其他載入方式重試。
Win11 穩定性、整體字級及畫質也尚未完成。

## 下一個有限內容切片

1. 以既有資源目錄與命令線索，挑出用途明確的剩餘標準 UI，先列原文語境、
   擬譯術語、資源 ID、格式與長度限制；不硬湊項數。
2. 建議先做約 20–40 個可明確追蹤的位置；無上下文者保留待查。
   使用既有抽取／建置與合成測試，不新增安裝架構。
3. 更新 catalog 與獨立版本 recipe、預期輸出 hash，保留 m020 與目前候選。
   只能在本機使用原檔建立新預期值；不公開原資產。
4. 將一小組可到達畫面併入下一次集中驗收，與「靜態通過」分開記錄。

涉及動態 CP932／HF 的下一切口，先做一條有來源、呼叫鏈及容量證據的
最小文字路徑，再考慮批量翻譯；不以安裝工具已通過代替顯示路線證明。
