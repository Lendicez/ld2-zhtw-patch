## 剩餘來源

1. 一般 UI 語境候選 219 個，其中設施類別 9 個（462／464 的建立鏈未確認）；
   其他功能群宜整批核對，勿按候選總數直接套翻譯。
2. 委託詳情的動態期限／報酬／內容：formatter 與版面離線研究完成，
   live Unicode／MFC 分支及原生 ABI／生命週期未證明，沒有動態 patch。
3. EXE 內 CP932 訊息、清單與名稱：完整 buffer、DBCS 和繪字路徑尚未打通。
4. HF／外部資料的劇情、委託、道具與魔法說明：安全抽取回寫與語境映射未完成。
5. 存檔標頭既有日期文字未修復；圖片內文字暫不處理。

540 組離屏控制項尺寸通過，頁籤／實際字型／動態覆寫仍待一次集中驗收。
Win11 穩定性、字型大小與畫質優化未因這批翻譯而完成。
本批與 m040 先只準備本機待發布清單，沒有遠端寫入。
