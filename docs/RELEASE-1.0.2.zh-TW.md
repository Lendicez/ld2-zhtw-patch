# 俠客遊 前途道標 繁體中文化補丁 1.0.2

發行日：2026-11-16。經專案擁有者實機確認（測試版 rc1，由 1.0.1 更新）後出版。原始碼：分支 `release/1.0.2`（commit `240f590`）。

- 支援版本、需求、安裝程式行為同 [1.0.0](RELEASE-1.0.0.zh-TW.md)。
- 已裝過 1.0.0 或 1.0.1：直接執行本版安裝程式，會顯示「更新」，只更新有變動的檔案，不必先解除安裝。

## 修正

- **存檔畫面的存檔清單亂碼**（讀檔畫面原本就正常）：「檔案 → 儲存遊戲」的清單各列現在顯示為「000: 971年 7月12日 ○○○ 岩塊鎮」（KNOWN-ISSUES #11）。
- **酒館傳聞視窗標題亂碼**（例「?惕W???D-男」）：中文標題接上日文名字時，中文部分被拆壞。清單、標題、對話框的轉換改為逐段判斷中日文（#12）。
- 右鍵選單「開場動畫」統一為「片頭動畫」；除錯對話框、名稱輸入對話框的用詞與其他畫面一致。

## 改進

- **人名音譯**：隨機產生的角色名（以及其他查不到既有譯名的片假名名字）音譯更自然——拗音不再拆成兩個字
  （例：西亞爾 → 夏爾、特伊斯 → 提斯、德伊歐 → 迪歐、夫伊羅 → 菲羅）。清單、標題與傳聞／訊息內文採同一套規則，
  不再出現同一個名字在清單是中文、在訊息裡是日文片假名的情況。只影響顯示，不寫入存檔。
- **圖片按鈕**：角色詳情分頁「物品1／物品2」改為「道具1／道具2」（與全書用語一致）；分頁「能力／戰力」與
  「確定／取消／下一頁／返回」按鈕改用與遊戲介面相同的細明體點陣字，筆畫更清楚、整排字形一致。

## 存檔相容性

- 與 1.0.1 相同，沒有新的變更。

- 自動回歸 12 組（旅館／酒館／情報所／訓練所、商店、武器店與移動、酒館傳聞、介面設定、角色視窗、住宿天數、委託、
  戰鬥五個指令、創角到存檔、讀回新角色）以安裝程式實際安裝的遊戲執行，全數通過。
