## 語境證據

原版 1.0.3.16 的 WM_COMMAND 訊息表位於 file offset 0x159e60，
32865–32875 的分派函式為 0x88350。其 0x8840b 跳躍表以 32866 為基準。
使用既有 Capstone 逐指令核對分支及直接呼叫，並讀取固定版本的對話框表：

| 命令 ID | 表索引 | 對話框 | 類別 |
|---:|---:|---:|---|
| 32866 | 46 | 120 | CSelectAttackDlg |
| 32869 | 47 | 121 | CSelectDefenceDlg |
| 32870 | 48 | 518 | CRunawayDlg |
| 32872 | 50 | 122 | CSelectSkillDlg |
| 32873 | 51 | 123 | CTurnFormationDlg |

分支呼叫既有 0xd0530 對話框分派器，表中的資源 ID、類別名稱、factory
與 constructor 一致。共用建立路徑沿用 m020 已確認的 ANSI/MFC 邊界。
這證明靜態命令關聯；條件分支、目前遊戲狀態下可到達性及動態覆寫仍未實測。

選單 129 的戰鬥命令與 RT_STRING 32866–32873 一一對應，保留原本
換行分隔的提示／短標籤結構。魔法、道具及技能選單本來就是相同中文字，
沒有為湊數重寫；這些命令的日文提示仍需要翻譯，因此本批處理提示字串。
「呼喊隊友」只翻譯操作文字，沒有推論或更改其遊戲效果。
