## 語境與頁面建立證據

與前幾批一般對話框不同，這批主要是 CBasePage 衍生頁面。
共核對 28 條類別路徑，對應 27 個不同資源：類別描述記錄 → factory →
constructor → CBasePage 的 0x31860 → template initializer 0xf0d0e。
資源 ID 的 push 值及 constructor call 均由已安裝 Capstone 解碼確認，
再以有原檔的測試核對相對呼叫與有限位置常數；不公開原始指令 bytes。
shared initializer 的 0xf0d3a 將模板 ID 放入頁面描述，提供資源身份證據。
這不等於證明完整主選單呼叫鏈、條件可達性或執行時可見內容。

本機原版附帶手冊的 cont3-8／9／10／11.html 分別補足購售、寺院、訓練與
情報、住家功能語境。已確認「手形」用於進入其他國家的首都，故譯為
「通行證」，沒有猜成票券或金融票據。僅記錄檔名、原檔 hash 與自有摘要，
不納入完整手冊原文。其他通用欄位以頁面角色、控制項型別及相鄰欄位確認。

暫緩原因：
- 資源 462：CShopDarkInfoPage 的 constructor 實際指定 142；不能因類別名稱
  相似就宣稱 462 是該頁面。五個位置全部保留，未判定它未使用。
- 資源 464：尚無可靠頁面建立鏈，特殊物品／地點名稱和條件可達性未核實。
  四個位置全部保留，不靠命名猜測翻譯，也未調整其字型。

## 重建與測試

新 profile 為 patches/m041，CLI 必須明確指定 --profile m041。
預設仍是 m020；現有單 EXE 打包候選未重包，也不因此啟用正式安裝。
白名單原版 SHA256：
6c817a0978cd9f02b66a7f15e6e46b752e490eaffaa520e18d360d296d40d5d2。
候選為 7,114,752 bytes，SHA256：
bedee9b18527f1f3a3a264ac175fa968ce24bf41beb6070a82988eeaf6cd5177。

兩份 EXE 與 build.json 逐 byte 一致。相較 m038 僅 27 個 dialog payload 改變；
沒有改 menu／RT_STRING、本輪以外資源、程式／資料區、manifest 或動態文字。
所有對話框／控制項幾何、ID、樣式、順序與額外控制項資料保留，
dialog 292 與 m038 逐 byte 相同，因此明確排除 m040 版面候選。
原版清單 1,029 檔雜湊重核相同，沒有讀取或更改私人存檔內容。

驗證結果：
- 123 個新位置通過 Python 與 Windows 原生 CP950 嚴格往返，無替代字元。
- 984 個逐項格式負面案例拒絕 %d／%s／%%、換行、NUL、快捷鍵／Tab 注入
  及 CP950 無法表示的字元。原新譯文本身無 printf 參數或助記鍵。
- 135 個靜態控制項，於 96／120／144／192 DPI 共 540 組 memory-DC 量測，
  加入按鈕／radio／groupbox 預留寬度後均符合既有矩形，沒有缺字。
- 新增 8 個測試，涵蓋處置去重、原文錨點／格式／箭頭／空白契約、原生轉碼、
  版本混用拒絕、重現重建、27 個限定資源差異及類別／factory／模板關聯。
- 一般套件 304 項：225 通過、79 跳過、0 失敗。
- 含合法原檔 304 項：238 通過、66 跳過、0 失敗。兩次結果不能相加；
  缺原檔、未 opt-in 的原生交易／程序中斷等 skip 不計通過。

## 尚需一次集中遊戲驗收

離屏量測並不是 property-sheet 的實際畫面。27 個頁面標題可能用於頁籤，
其可用寬度、分頁、實際父頁字型／DPI 尚未觀察；MFC 也可能重新套字型。
訓練狀態、目前房屋名稱、價格、任務期限／報酬、清單內容等可能被動態
資料覆蓋。本批只處理初始資源文字，不能宣稱這些動態文字已翻完。

後續取得集中驗收時段及適當可丟棄測試狀態後，合併查看：
1. 常見商店購售／說明、住宿、寺院、訓練、情報／通行證頁面文字與頁籤；
2. 住家保管／陳列、隊友／金錢與家族頁面，核對箭頭及取消／返回；
3. 只有正常遊戲條件可達時才查看黑暗公會／山頂頁，不改存檔造條件。
購買、捐款、隊友與家庭操作可能改變遊戲狀態，先以只開頁、返回為最小
驗收，後續功能操作僅用可丟棄存檔。不能到達的頁面明確留待測試。
本輪沒有要求使用者開遊戲，也沒有啟動此流程。

整體剩餘一般 UI 語境候選由 381 減至 219：123 新翻、39 確認可原樣保留。
設施類別自身仍有上述 9 個候選；其他世界／角色建立、互動、RT_STRING 等
優先依功能整批收斂。動態 CP932、HF、存檔標頭與圖片字不在此分母；
既有 Unicode 接入停止線不因這批資源翻譯而改變。
