## 新增：媒體診斷

沒有背景音樂、沒有音效或片頭動畫無法播放時，按安裝程式的「媒體診斷」，會以**遊戲相同的方式**（32 位元、同樣的系統元件）分別測試並顯示結果與可能原因：

| 項目 | 遊戲使用的方式 | 測試內容 |
|---|---|---|
| 背景音樂 | `music\*.wma`，DirectShow（需要 Windows Media 的 WMA 解碼器） | 載入 → 播放約 3 秒 → 跳到曲末確認能正常播完 |
| 音效 | `RES\*.WAV`，DirectSound | 開啟音訊裝置 → 播放一個音效 |
| 片頭動畫 | `avi\OPENING.avi`（Cinepak），MCI | 開啟 → 播放約 5 秒 |

- 只讀遊戲檔，不改系統或遊戲設定。
- 常見原因與處理：Windows N／KN 版缺少媒體元件（「設定 → 系統 → 選用功能」新增「媒體功能套件」）；遊戲檔損毀（Steam「驗證遊戲檔案完整性」）；沒有可用的播放裝置。
- 結果也會顯示 Windows 版本／組建與版本別（例如 N 版），方便回報問題時附上。

## 其他

- 安裝程式改為 32 位元程式（與遊戲相同），媒體診斷才能測到遊戲實際使用的元件。
- 提示文字加入「沒有聲音時按媒體診斷」；偵測到缺少 Windows Media 元件時也會提示。

## 驗證

- 媒體診斷：本機（Windows 11 25H2）三項皆正常（含曲末）；以缺檔與損毀檔測試錯誤訊息。N 版實機未測（沒有 N 版環境），只確認無法解碼時會顯示原因與「媒體功能套件」的指引。
