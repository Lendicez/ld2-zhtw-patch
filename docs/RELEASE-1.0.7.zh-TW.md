這一版修正擁有者回報的兩類顯示問題，並全面套用到補丁的所有文字轉換路徑。

## 修正：人名中出現「?」

- 例：角色詳情「女戰士的?奈」、委託清單委託人「吉岡 直?」。
- 原因：遊戲的人名表有日文漢字；轉成繁中（Big5）顯示時，Big5 沒有的字（日本新字體如「恵」「沢」「斉」「弥」，日本國字如「榊」「峠」）被系統換成「?」。
- 修法：轉成 Big5 前，先把這些字換成 Big5 有的對應字（恵→惠、沢→澤、斉→齊、弥→彌、国→國、竜→龍…；國字依字義：榊→神、峠→嶺、笹→筱、梶→柁、宍→肉…），共 685 字。
  對照表取材自 Unicode Unihan 異體字資料與 OpenCC，少數字人工指定；已用 Windows 的 CP950 核對。
- 遊戲人名表（約 840 筆）用到的 Big5 缺字已全部有對應。

## 修正：「使用魔法」等清單的目標名字亂碼

- 例：使用魔法／使用道具的「目標」清單，隊員名字變成亂碼。
- 原因：名字本來就是繁中（玩家自取的名字，或已音譯後存進存檔的名字），舊的清單轉換路徑把它當日文編碼再解一次。
- 修法：所有補丁的日文解碼都先判斷字串是否為「繁中夾日文」，是就逐段解碼（日文段用日文編碼、其餘用 Big5），純日文照舊。

## 全面檢查

- 依這兩類問題檢查補丁的全部文字轉換點（清單、標題、對話框文字、繪製文字、格式化字串、角色詳情）：
  兩項修正都放在共用的轉換入口（補丁程式中 11 處轉成 Big5、14 處日文解碼的呼叫點），所有路徑一起生效。
- 自動回歸與 1.0.6 相同；各測試畫面的控制項文字「?」／亂碼由 3 處降為 0（含使用魔法目標清單）。

## 驗證

- 模擬測試：缺字對應（含長度 -1、其他字碼頁不受影響）、純日文／純繁中／混合字串解碼、緩衝區大小查詢。
- 實機自動測試：使用魔法／使用道具目標清單顯示正確名字；自動回歸 11 組；由 1.0.6（免系統管理員＋自動存檔關）與 1.0.4 更新。
