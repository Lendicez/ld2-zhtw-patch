# m036 副本驗收候選版

本候選版將既有繁中來源檢查介面與 m035 單檔流程接合。
只有打包時綁定的新測試根目錄可建立副本；介面和 CLI 都不能更換此根目錄，
不能指定現有遊戲目錄作為安裝目標。正式 can_apply 維持 false。
它是本機集中驗收候選版，不是可公開散布的正式安裝器。

## 操作與復原資料

選原版資料夾、檢查版本後，按「準備新副本安裝」會先顯示來源、全新副本
及復原資料位置。按「確認執行」才建立檔案。取消／返回不寫入；來源或
程序狀態變動會拒絕執行。進行中禁止重複送出、返回及關閉。

安裝只會建立新的 ld2-trial 工作區。case-01 內只有 EXE、副本備份與交易
資料；recovery-store 是其外部同層資料夾。工具自動將復原憑據雜湊、版本、
工作區／副本身分，以 Windows 目前使用者的 DPAPI 保護後存入獨立檔案。
正常使用不需要抄 hash、編輯 JSON、設定密碼或安裝憑證。

重新開啟工具，按「開啟工作區並還原」並選取完整的 ld2-trial 資料夾。
工具先驗證受保護的憑據與檔案，再要求還原確認。已還原的副本只顯示狀態，
不重複寫入。缺少憑據、資料損壞、工作區被替換或 Windows 帳戶無法解密時
會拒絕復原，不改信任同一目錄裡的明文日誌，也不重建信任資料。

請保留整個工作區，並使用同一 Windows 帳戶；換電腦、重設帳戶或遺失
使用者設定檔後不保證可復原。DPAPI 不防禦能以同一帳戶任意執行程式的
攻擊者。未修改主機保護、ACL、登錄或憑證，也沒有使用 machine-scope。
只使用 UI_FORBIDDEN，沒有提示或新增登入流程。解密後仍檢查 envelope
checksum、嚴格 schema、用途與根目錄／副本身分。

Microsoft 來源：
[CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)、
[CryptUnprotectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptunprotectdata)。

## 範圍與限制

- 候選 EXE 是 asInvoker，拒絕以系統管理員執行；不會啟動遊戲。
- Steam 多候選流程以合成輸入測試。這輪沒有讀主機 Steam 登錄；本機
  候選介面上的 Steam 偵測按鈕仍停用，以免重試先前未獲確認的讀取。
- 測試根目錄的身分存在本機打包設定內；設定檔只進本機 binary，不上傳。
  根目錄不符即拒絕，沒有 runtime parent override 或正式安裝開關。
- 每次只處理一個新副本；保留原檔、備份及診斷。兩次 rename 有短暫
  檔名空窗，不宣稱原子替換、斷電／重開機安全。
- 憑據先成功保存並讀回，才允許 rename。保存失敗可能留下尚未修改的
  新副本及 stage；不自動刪除或以明文憑據繼續。
- 任何實際拒絕存取會停止該工作階段，不改權限或換途徑重試。
- 原有單純輸出新檔案的 CLI 仍保留；它沒有安裝現有遊戲目錄的能力。

## 一次集中驗收建議

先約定一次 5–8 分鐘的候選介面驗收，使用者可手動操作，不需反覆切回視窗：
1. 正常權限開啟候選版，確認繁中字、長路徑換行、按鈕、焦點與目前 DPI。
2. 指定原版資料夾，確認來源版本及目標均可讀；正式安裝保持停用。
3. 進入確認畫面後取消／返回，確認沒有建立副本。
4. 確認建立新副本；快速重複點擊不得開始第二次操作，結束後顯示工作區。
5. 關閉再開啟候選版，選該工作區還原；再次選取應顯示已還原。

GUI 視覺與上述真實按鍵流程尚未執行；Tk 被打包不等於畫面通過。

遊戲部分另預留約 10 分鐘，前置條件是事先準備並核准完整依賴測試副本與
原遊戲所需的正常 UAC。目前 EXE-only case 不是可啟動的完整遊戲，
本候選也不會自動補齊資產或啟動它。屆時集中檢查標題／主選單、
存讀檔確認、取消／返回、繁中字與裁切、一次測試存檔、退出及重啟讀回。
任何 Windows 封鎖立即停止，不改防護。正式存檔不得帶入。
