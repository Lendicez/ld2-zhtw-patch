### 推論與限制

- 遊戲本身不需要系統管理員權限；requireAdministrator 只在遊戲裝在受保護資料夾（如 `C:\Program Files (x86)\Steam`）時，
  讓存檔寫得進去。manifest 有 trustInfo，改成 asInvoker 後 Windows 不會做檔案虛擬化，裝在 Program Files 時存檔會失敗。
- `dpiAware=true` 表示 Windows 不替遊戲放大；縮放 150% 以上的螢幕（筆電、4K）畫面與字會偏小。擁有者主機為 100%，不受影響；
  其他縮放比例未量測。
- 長時間實玩（數小時、迷宮與戰鬥反覆）、音效／MIDI、影片播放、全螢幕切換未量測。
