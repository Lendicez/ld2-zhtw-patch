基底為 PR #15 的 a74c1f542bfb6631f631a53325446a86396118e7。

## 靜態證據與分類修正

六條 descriptor／class／factory 綁定核對資源 132、154、168、169、173、180；
其中迷宮移動、休息與角色類型的 descriptor kind 為 6，不能只搜尋 kind 5／7。
十條頁面 constructor 綁定涵蓋人物互動、隊友交談、技能、交接及歷史／資料頁。
另外八條直接 constructor 綁定涵蓋文字輸入、世界、生日、道具整理、彩券數字／
購買張數、金錢和交接頁。每條有限位置常數有原檔整合測試；不公開原始指令。
固定參數傳入 0xeaeb6 後保存模板 ID；頁面路徑使用已確認的 0x31860。
這些是資源身份與有界指令證據，不等於證明每個功能在正常遊戲條件下可達。

原盤點的「角色／世界建立」只是文字分類。資源 180 同時具有關係／國別／
HP／MP 排序，因此本輪正確描述為角色類型篩選，不聲稱它建立玩家角色。
四個國名整組保留，避免在缺專名對照時自行音譯或只改部分選項。

標準主選單的 command ID 與相同 ID 的 RT_STRING 提示核對，保留換行角色。
共享字串載入器 0x5860 取 RT_STRING 後轉為窄字串，故仍為限定 ACP950 路線。
八個錯誤／狀態提示有直接載入證據；四個視窗標題有 descriptor 身份，
其他標題有 +0xe0 caption ID 及共用載入路徑證據。實際顯示與覆寫仍未觀察。
32775、32777–32783 是設定名稱。以 32777 為例，載入後進入 0xf2e8f，
其分支呼叫 RegQueryValueExA 或 GetPrivateProfileIntA；因此不翻譯這些識別。
本輪只讀取程式碼，沒有執行這些登錄／INI 查詢。

## 驗證與可重現建置

一般完整回歸 314 項：232 通過、82 跳過；含合法原檔 314 項：248 通過、
66 跳過，均零失敗。兩個套件不可相加，未 opt-in 原生交易等 skip 不算通過。
134 個 Windows 原生 CP950 往返、1,072 個逐項格式負面案例通過。
340 組固定控制項離屏量測於 96／120／144／192 DPI 通過；另有 336 組
標題／選單／訊息行固有尺寸與缺字檢查，不將它們冒稱固定容器不裁切證明。
原選單已有重複助記鍵，逐層比對確認沒有新增衝突，沒有改掉原快捷鍵。
一般及 extended dialog 的矩形欄位分別依正確格式讀取；沒有調整幾何。

最終兩次 EXE 與 build.json 逐 byte 一致，輸出 7,118,848 bytes，SHA256：
9fea1172e92167d435a8ec26baf085ab45a2a56468690bf7bfec1f8ba29dc367。
原版 SHA256：6c817a0978cd9f02b66a7f15e6e46b752e490eaffaa520e18d360d296d40d5d2。
PE 程式／資料區不變；僅白名單資源文字／字型及必要 PE 資源表／大小／checksum
可變。原版 1,029 檔雜湊相同；舊 profile、m040 版面、先前輸出均保留。

   有候選與局部鏈，但安全容量、指標／長度、DBCS 切割及繪字端尚未全面證明。

   518 個 BMH、47 個 TIL。這是封裝／檔案類別盤點，不能推定它們都是劇本。
   尚未有證據把外部劇情全集、文字記錄界線、壓縮格式與實際載入器完整對上。
   舊文所稱 HF 研究也不是已確認的外部劇本來源；沒有直接改未知封裝。
4. HTML／CHM 說明與圖片文字是其他來源；手冊僅作語境參照，未整批翻譯或

## 最小集中遊戲驗收場景（本輪不執行）

使用一個獨立可丟棄完整副本、已識別測試存檔，安排單次集中操作。
沒有測試狀態時不改存檔造條件，僅記錄缺口；主機啟動和正常 UAC 仍另行確認。

1. 起始／設定／世界與角色選擇：查看標題、MMX 狀態、篩選選項與排序，
   取消返回；world／生日僅在正常流程可到達時看，不宣稱全部都會出現。
2. 城鎮：一次查看主選單、提示列、迷宮／其他城鎮移動、休息、委託一覽與詳情，
   核對通行證欄、等待語意、期限與動態內容；不要求實際跨城或完成委託。
3. 常用設施：商店、旅館、寺院、訓練、情報與住家，集中看頁籤、字型及返回。
4. 道具／人物：整理與交接、交談、邀請、偷竊、襲擊和給錢頁，只開頁與取消；
   不執行會改變世界／隊伍的動作。彩券、歷史與特殊設施僅在可達條件下查看。
5. 同一副本的可丟棄存檔儲存、正常退出、重啟讀回；核對存檔相容與版本。
   不故意製造磁碟不足／壞檔來觸發錯誤提示，未看到的提示保留離線狀態。

集中記錄實際字型／DPI、頁籤裁切、動態覆寫、返回與存讀檔。不同資料夾
不是安全隔離，不能保證原遊戲的所有外部寫入可回復。未做本輪 GUI 驗收。


## 發布前容量掃描規則

累積 m042 catalog 為 499,730 bytes，超過舊掃描器 400,000-byte 單檔門檻。
首次本機掃描因此失敗，並非發現秘密或原始二進位，也不是平台權限拒絕。
現僅允許該固定路徑、精確大小與 SHA256 的已審核 catalog，且須通過 552 項
catalog schema。其他檔案上限保持 400,000 bytes；NUL／MZ／UTF-8、秘密、
大段編碼內容、私人路徑、Git index 與白名單掃描全部照常執行。
新增兩個測試拒絕改名、內容篡改、超長與未審核 payload。此修正不改遊戲輸出。
